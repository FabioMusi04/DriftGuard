# Security policy

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for the repository if enabled, or contact the repository maintainers privately.

Until a public repository and private reporting channel are configured, do not assume that a public issue is a confidential channel. Avoid uploading configuration files, credentials, tokens, or CI artifacts when describing a report.

DriftGuard is currently an early MVP. Its best-effort output redaction is not a guarantee that arbitrary secrets will be removed.
